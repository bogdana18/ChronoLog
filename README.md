# Time tracker "Chronolog" - an application to track times for project

### To start the project you should 
- clone git repository
- npm i
- npm run dev

## You can:
- create and delete a project
- close and open projects
- add start time and add end time to project when create
- minimum time is 15 min
- time cannot be added to completed projects
- view all worklogs
- overlapping times can be merged
- view total spend time
- time added to project should fits start and end periods

## Stack: 
- NestJS
- TypeORM
- SQLite
- React
- TailwindCSS
